# 0051. A voice holds one engine, rebuilt in place

- **Status:** Proposed
- **Deciders:** project owner
- Supersedes [0008](0008-persistent-engine-instances.md) (engines are
  persistent, one instance of each per voice).

## Context
ADR 0008 kept one instance of every engine in each voice because the
alternative it measured, an enum whose new variant is built by value and
moved in, put a 66 KB `ModalEngine` on an unguarded interrupt stack. That
risk was about building by value, not about holding one engine.
`chimera-core/src/in_place.rs` now builds a `repr(C, u8)` enum's variant
where the enum lives (`in_place_enum!`), with no stack temporary. Holding
every engine costs the sum: a `Voice` is 35,248 B, 32,736 B of it Modal, and
Modal 2's exciters need room in D2.

## Decision
A `Voice` holds an `EngineSlot`, a `repr(C, u8)` enum generated by
`in_place_enum!` with one variant per engine (`Algo`, `Modal`). The variant
is the engine: no separate field records which one is active, and every
dispatch is an exhaustive `match` on the slot. The slot is rebuilt in
place, through each engine's field-wise `init_in_place`, when a fade ends
(`Voice::reset` rebuilds into the Sound's kind) and when an idle voice
triggers a different engine. Nothing builds an engine by value in the audio
path. `size_of::<EngineSlot>()` is at most the largest engine plus the
slot's align, and a `Voice` at most `VOICE_CHAIN_BYTES` (2,048 B) plus its
slot; both are asserted.

## Alternatives considered
- **Keep `Engines`** (one instance of each) — memory is the sum, and it grows
  with every engine and every Modal 2 exciter.
- **A by-value enum** (`*slot = EngineSlot::Modal(ModalEngine::new(..))`) —
  the ADR 0008 hazard: the engine is built on the stack and moved in.
- **A shared buffer pool** — aliasing between voices to manage, and every
  voice still needs its own state for the engine it plays.

## Consequences
Memory is the largest engine, not the sum (a `Voice` is 34,576 B on the host,
and Modal's own models become exclusive in a later step). A voice rebuilds at
most twice per block (a fade end, then the note waiting on it); the rebuild
is not billed in `Cost`, as the reset it replaces wasn't. The new `unsafe`
lives in `in_place.rs` only: callers pass an in-place constructor, one
`// SAFETY:` line per arm.
