# 0323. Keep controller maps flat, up to 90 rows, shared per map in AXI, with one factory map an engine

- **Status:** Accepted (2026-11-23)
- **Deciders:** owner (model 2026-11-12, reaffirmed 2026-11-22 in #1103; #1099 from dspmax; the four open questions of #1122 decided 2026-11-23), firmware
- **Supersedes:** 0266 (whole); 0226 in part (its sections, the layer merge, `MapSection` as the written record, the 16-row layer); 0264 (SUGGEST). Amends 0255 (a row edit is written from RAM, not read-modified-written) and 0288 (a map row is retargeted, and `+ NEW BINDING` adds to the picked map).

## Context
The owner's model (#1103): a controller map is one flat list of learns, up to about 90 rows, with no shared or engine sections. Any map plays on any engine, and rows the engine lacks are dimmed. The factory ships one rich map an engine, named after it (ALGO, MODAL, VA, TAPE, DRUM), as starting points. A Part holds a map only once it picks one, NONE holds nothing, and the map stays with the Part across Sound changes. RAM is a fixed reservation sized for the worst case (6 Parts × ~90 rows × 8 B ≈ 4.3 KB) in AXI, since D2 is full; Parts on one map may share a copy. #1099 asks for a `+ NEW BINDING` row, retargeting without learn, and finer control of a row's range.

ADR 0266 (Proposed) put 90 rows of 12 B a Part in ITCM with a streaming codec and a bank-1 module. The owner's 2026-11-22 brief moves the rows to AXI at 8 B a row and keeps the code behind the existing doors (bank 1 frozen, ADR 0198). ADR 0288 (Accepted) already gives the Sound's rows `+ NEW BINDING` and retarget by pointing.

## Decision
- **A map is one flat list of at most 90 rows** (`MAP_ROWS`; `MapLen`, `MapRowIx`). A target appears once. A row is 8 B in RAM: the `Bindings` v1 disk row, decoded on use. A SysEx row's 4-B key sits in its map's key table of 16 (a Sound's whole map fits), the row naming its index; a 17th key is `MAP FULL`.
- **RAM: one pool, shared.** Six map slots (one a Part, the worst case) and a file buffer, a fixed static in AXI `.bss` (about 6 KB), reached through one pointer in `MidiSlot`. Parts on the same map point at the same slot. Picking can never take more.
- **RAM is the truth.** A row edit, add, drop or retarget changes the shared slot at once and marks it dirty; the next card work writes the whole map. A pick reads the card; a console `put`/`rm` or another card reads again.
- **Seats.** A Part's runtime keeps 32 binding slots: the Sound's 16 rows, then 16 seats (ADR 0226's layer slots). A map change seats the ECHO rows first, then rows in map order, live and unshadowed only. A message no Sound row or seat hears scans the map and seats its rows into the resting seat heard least recently, resetting only that slot; with none resting it is dropped. A map of up to 16 rows plays exactly as before.
- **The Sound's own rows win** a control over the map's, as before (a shadowed map row dims).
- **File.** ADR 0226's frame; the body is `MapRows` records (`0x8024`, critical), each a `Bindings` payload of up to 16 rows, in order. Old `MapSection` files load flattened in file order, duplicates keep the last, rows past 90 skipped and counted; the next save writes `MapRows`.
- **Factory maps** ALGO, MODAL, VA, TAPE and DRUM, generated by `chimera-utils engine-maps` through `ctl::save`, replace SUGGEST in the factory pack. Shared cells (ENV 1–3 in both ENV TYPEs, LFO 1–3, filter, FX slot, pitch, out) come first and sit on the same CC in every map; then the engine's own cells. CCs are those `LearnCc` passes less ADR 0263's built-ins and 1, 2, 4, 65–69, 84, MIDI's undefined ones first. Cells the built-in layer already drives are left out. Absolute `Jump`, echo off.
- **MIDI MAP.** Row 0 picks NONE or a card map. Then the map's rows, the Sound's rows and `+ NEW BINDING`. With a map picked, `+ NEW BINDING` adds to the map; with NONE, to the Sound. EDIT on any row retargets it by pointing (ADR 0288), its control, range, input and echo kept.
- **Finer range: a fine step.** MIX held while turning C or D moves MIN or MAX by one place a frame, with no acceleration. The span stays 256 places: that is already twice a 7-bit control's resolution, so more bits would not be heard from a CC, and they would grow every Sound's map and the disk format. What made the range hard to set was the accelerated turn jumping 2–10 places.
- **Editor protocol.** `ed` stays protocol 4: map rows are `M1` to `M90` in `row`, `map set` and `map rm`.
- **Placement.** The flat map, codec and file are `midi_map::ctl` (bank 2's existing glob); the pool and seats are `ui::midi` (bank 2's). Bank 1 gains the pool's static and pointer, and `RecordTag::MapRows`. No door entry is added.

## Owner's decisions (2026-11-23, on #1122)
- DRUM's pad and kit cells stay unmappable in 0.4; DRUM's factory map holds the shared cells and the master FX. A mapping that follows the selected pad, Elektron-style, is #1124 (0.5).
- The AXI reservation of about 6.9 KB (the six slots, the empty map and the file buffer) is accepted.
- Echo goes out for seated rows only: 16 a Part, ECHO rows seated first.
- MIDI MAP lists 16 maps: the five factory maps and 11 user maps before `CARD HOLDS MORE`.

## Alternatives considered
- **ITCM rows (ADR 0266).** It needed a linker region, a bootloader check and a unit check of an untried memory; AXI has room.
- **12-B `Binding` rows in RAM.** About 6.5 KB; 8-B rows match the owner's reservation and the disk row.
- **One copy a Part.** Two Parts on one map would need an edit to reach the other copy; sharing makes the edit visible at once.
- **Runtime state for every row.** About 55 B a row a Part: no region holds 30 KB.
- **Wider span resolution.** See the fine step above.
- **Pad and kit cells in the DRUM map.** They have no disk code and follow the selected pad; listed for the owner.

## Consequences
- 0.3 firmware refuses a 0.4 map file (critical record): a downgrade sees no map.
- SUGGEST's CC layout (ADR 0264) is no longer shipped; a SUGGEST file on a card still loads, flattened.
- **Measured** (orbit release build, merged with origin/0.4 6b85290ab):
  - RAM: AXI `.bss` +6912 B (the pool: six 786-B maps, the empty map, the 1214-B file buffer, the slots' state); D2 −776 B (`Layers`' scratch out, the seats' stamps in).
  - Bank 1: +104 B (`RecordTag::MapRows`, the pool's static and pointer, MIDI MAP's MIX hint and its field).
  - Bank 2: +8256 B. `midi_map::ctl` is an S4 group (S0–S3 had overflowed by 352 B).
  - Factory maps: ALGO 86 rows, MODAL 77, VA 74, TAPE 84, DRUM 86 (86 CCs in all; 51 shared rows).
- No call into bank 2 may be shared by the machine outliner (ADR 0175): `part_map` reads the pool inline (its empty map is a field, not a static), and the seat helpers are inlined loops, not closures.
