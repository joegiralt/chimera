# DMA Circular Buffer Audio Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace FIFO polling with DMA1_Stream0 circular transfer so SAI1_A plays a continuous 440 Hz sine with zero dropouts, independent of the main loop.

**Architecture:** DMA1_Stream0 reads from a 256×i16 static buffer in RAM_D2 (0x30000000) and writes to SAI1_A DR. Half-transfer and transfer-complete ISRs fill the inactive half with sine samples. DMAMUX1 channel 0 routes SAI1_A requests (ID 87) to DMA1_Stream0.

**Tech Stack:** `stm32h7xx-hal 0.16` (feature `stm32h750`, maps to `stm32h7` PAC module `stm32h743`), `cortex-m-rt` interrupt macro, direct register access.

**Spec:** `docs/superpowers/specs/2026-04-20-dma-audio-design.md`

```rust
/// DMA audio buffer in RAM_D2 — 256 × i16 = 128 stereo pairs.
/// DMA reads one half while ISR fills the other.
/// Note: RAM_D2 is NOLOAD, so this initializer is not applied by startup code.
/// `prefill_buffer()` must be called before DMA starts.
#[link_section = ".ram_d2"]
static mut AUDIO_BUF: [i16; 256] = [0; 256];

/// Phase accumulator for sine generation — only accessed from DMA ISR.
static mut SINE_PHASE: u32 = 0;

/// 256-entry sine lookup table (i32, 50% amplitude).
static SINE_TABLE: [i32; 256] = {
    let mut table = [0i32; 256];
    let mut i = 0;
    while i < 256 {
        let t = i as f64 / 256.0;
        let x = t * 2.0 * 3.14159265358979323846;
        let x = x - (6.28318530717958647692 * ((x / 6.28318530717958647692 + 0.5) as i64 as f64));
        let x2 = x * x;
        let x3 = x2 * x;
        let x5 = x3 * x2;
        let x7 = x5 * x2;
        let x9 = x7 * x2;
        let x11 = x9 * x2;
        let s = x - x3 / 6.0 + x5 / 120.0 - x7 / 5040.0 + x9 / 362880.0 - x11 / 39916800.0;
        table[i] = (s * 0.5 * 2147483647.0) as i32;
        i += 1;
    }
    table
};
```

- [ ] **Step 2: Add `fill_sine_buffer` function**

```rust
/// Fill 128 i16 samples (64 stereo pairs) starting at `offset` in AUDIO_BUF.
///
/// # Safety
/// Only called from DMA1_STR0 ISR — single interrupt, non-reentrant.
fn fill_sine_buffer(offset: usize) {
    // SAFETY: only accessed from single non-reentrant ISR
    unsafe {
        let phase_inc: u32 = 39_472_883; // 440 Hz at 47917 Hz
        for i in (0..128).step_by(2) {
            let idx = (SINE_PHASE >> 24) as usize;
            let sample = (SINE_TABLE[idx] >> 16) as i16;
            AUDIO_BUF[offset + i] = sample;     // left
            AUDIO_BUF[offset + i + 1] = sample; // right
            SINE_PHASE = SINE_PHASE.wrapping_add(phase_inc);
        }
    }
}
```

- [ ] **Step 3: Add `prefill_buffer` public function**

```rust
/// Pre-fill the entire AUDIO_BUF before DMA starts.

    fill_sine_buffer(128);
```

- [ ] **Step 3: Add `init_dma()` function**

```rust
use cortex_m::peripheral::NVIC;
use stm32h7xx_hal::pac::interrupt;

// SAI1 Block A data register address: base 0x40015800 + CHA offset 0x04 + DR offset 0x1C
const SAI1_CHA_DR: u32 = 0x4001_5820;

/// Configure DMA1_Stream0 for circular transfer from AUDIO_BUF to SAI1_A.
///
/// Must be called after `init_sai1a()` and `prefill_buffer()`, before `enable_sai()`.
pub fn init_dma() {
    // SAFETY: single-threaded init, peripheral register access before interrupts are unmasked
    let rcc = unsafe { &*pac::RCC::ptr() };
    let dma1 = unsafe { &*pac::DMA1::ptr() };
    let dmamux = unsafe { &*pac::DMAMUX1::ptr() };

    // Enable DMA1 clock
    rcc.ahb1enr.modify(|_, w| w.dma1en().set_bit());
    cortex_m::asm::delay(100);

    // Disable stream before configuration
    dma1.st[0].cr.modify(|_, w| w.en().disabled());
    while dma1.st[0].cr.read().en().is_enabled() {}

    // Clear all interrupt flags for stream 0
    dma1.lifcr.write(|w| {
        w.ctcif0().clear()
         .chtif0().clear()
         .cteif0().clear()
         .cdmeif0().clear()
         .cfeif0().clear()
    });

    // SAFETY: 87 is the valid DMAMUX request ID for SAI1_A (RM0433 Table 121)
    // DMAMUX: route SAI1_A (request ID 87) to DMA1_Stream0 (channel 0)
    dmamux.ccr[0].modify(|_, w| unsafe { w.dmareq_id().bits(87) });

    // SAFETY: writing valid peripheral/memory addresses and transfer count
    dma1.st[0].par.write(|w| unsafe { w.pa().bits(SAI1_CHA_DR) });
    dma1.st[0].m0ar.write(|w| unsafe {
        // SAFETY: AUDIO_BUF is static, address stable for lifetime of program
        w.m0a().bits(AUDIO_BUF.as_ptr() as u32)
    });
    dma1.st[0].ndtr.write(|w| w.ndt().bits(256));

    dma1.st[0].cr.write(|w| {
        w.dir().memory_to_peripheral()  // Memory -> SAI
         .circ().enabled()              // Circular mode
         .minc().incremented()          // Memory address increment
         .pinc().fixed()                // Peripheral address fixed
         .msize().bits16()              // 16-bit memory transfers
         .psize().bits16()              // 16-bit peripheral transfers
         .pl().very_high()              // Highest DMA priority
         .htie().enabled()              // Half-transfer interrupt
         .tcie().enabled()              // Transfer-complete interrupt
    });

    // SAFETY: DMA1_STR0 ISR is defined in this module; buffer is pre-filled;
    // unmasking is safe because the ISR only touches AUDIO_BUF and SINE_PHASE.
    unsafe {
        // Priority: 3 (below display SPI=2 and MIDI USART=1)
        let mut core = cortex_m::Peripherals::steal();
        core.NVIC.set_priority(pac::Interrupt::DMA1_STR0, 3);
        NVIC::unmask(pac::Interrupt::DMA1_STR0);
    }

    // Enable DMA stream
    dma1.st[0].cr.modify(|_, w| w.en().enabled());
}
```

### Task 5: Add DMA ISR handler

**Files:**
- Modify: `chimera-stm32/src/audio.rs`

- [ ] **Step 1: Add the DMA1_STR0 interrupt handler**

Add at the bottom of `audio.rs`:

```rust
#[interrupt]
fn DMA1_STR0() {
    // SAFETY: ISR has exclusive access to DMA1 status/clear registers;
    // fill_sine_buffer only touches AUDIO_BUF and SINE_PHASE from this single ISR
    let dma1 = unsafe { &*pac::DMA1::ptr() };

    if dma1.lisr.read().htif0().is_half() {
        // Half-transfer: DMA is reading second half, fill first half
        dma1.lifcr.write(|w| w.chtif0().clear());
        fill_sine_buffer(0);
    }

    if dma1.lisr.read().tcif0().is_complete() {
        // Transfer-complete: DMA wrapped to first half, fill second half
        dma1.lifcr.write(|w| w.ctcif0().clear());
        fill_sine_buffer(128);
    }
}
```
