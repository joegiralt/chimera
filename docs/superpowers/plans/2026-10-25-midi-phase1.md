# Chimera 0.3 MIDI Phase 1 (DIN) Implementation Plan

**Goal:** Make generic MIDI controllers and sequencers work properly over DIN, with:
- a two-layer typed parser;
- a frozen NRPN address for every stored param;
- a binding model in which every input names its kind (absolute with takeover, one of four relative encodings or increment/decrement, button);
- learn that senses the kind;
- per-Part value echo out of DIN;
- a Universal Identity Reply.

**Spec:** `docs/superpowers/specs/2026-10-25-midi-phase1-design.md`. Read it, `CLAUDE.md`, ADR 0198, 0139 and the two drafts below before any task.

**ADRs:** `docs/adr/0216-every-parameter-has-a-frozen-nrpn-address-from-its-disk-identity.md`, `docs/adr/0217-controllers-bind-through-one-typed-model.md` (both Proposed).

**Architecture in one paragraph.** A new leaf crate `chimera-midi` holds the pure code: value newtypes, the layer-1 `Parser`, the layer-2 `Controllers`, and the relative, takeover, law, learn, out, SysEx and sensing arithmetic. Its value types stay in bank 1; every other module is linked into bank 2. `chimera-engine` derives the NRPN address space from the frozen disk identity. It also holds the `Binding`/`Input`/`MidiMap` types, the `DinPipe` that the USART1 ISR feeds through `Bank2Door::midi`, the `CtrlRing` the UI drains, the `OutRing` the TX interrupt drains, and the map codec. `chimera-core` resolves bindings, senses learn, plans echoes and draws MIDI MAP behind a new `MidiUiDoor` slot (`DOOR_ADDR + 0x300`). Bank 1 keeps only types, rings, stubs and spec data.

**Base:** branch `midi-03` from `origin/main` 4eae5d81. Merge `origin/main` before Task 1 if it moved, and re-run Task 0.

## Global constraints

- **Code rules:** no `unsafe` without `// SAFETY:` (`chimera-midi` is `#![forbid(unsafe_code)]`). No heap, no blocking and no new audio-thread work. No libc.
- **Type-driven:**
  - Every MIDI quantity is a newtype with a checked constructor (`U7`, `U14`, `Channel`, `Key`, `Velocity`, `Bend`, `Ctrl`, `FreeCc`, `LearnCc`, `Cc14Msb`, `Place`, `NrpnAddr`).
  - Every mode is an enum.
  - `Input` makes illegal control/kind pairs unrepresentable.
  - No `u8` crosses a module boundary where a newtype exists.
- **Functional core, imperative shell:** every decision is a pure function in `chimera-midi` or `chimera-engine`, tested on the host. The ISR stub, the UI stubs and the desktop glue only move bytes and call the door.
- **Bank 1 frozen (ADR 0198):**
  - A new function goes to bank 2: a `bank2.x` glob in `chimera-stm32/build.rs` and a pattern in the Justfile's `check-door-placed`.
  - A task that moves code out lowers lines with `BANK1_LOWER=1 just check`.
  - A raise is allowed only for ADR 0217's listed exceptions, measured, with `# ADR 0217` on the line.
- **Never snap:** every absolute move goes through ADR 0139's ramp and the knob glide. Every relative move goes through `edit_addr`.
- **Frozen codes:**
  - Record `Bindings` = `0x001F`, not critical. `0x001E` is read only.
  - `disk_codes_v1.txt` and `neutral_v1.txt` stay byte-identical.
  - `nrpn_v1.txt` is append-only once Task 6 writes it.
- **Copy:** labels exactly as spec § 8, full words where they fit. Every hidden gesture has a hint.
- **Build hygiene:**
  - Never more than 10 cores (`CARGO_BUILD_JOBS=10`), and at most two heavy builds at once.
  - `touch chimera-engine/src/lib.rs` after engine edits (stale-build guard).
  - No `/tmp`, no `git stash`.
- **Commits:** terse subject, no type prefix. Stage by path. Never stage `chimera.bin` or `docs/chimera-ui-ux-spec.md`.
- **Flash:** each task's report has one line: bank 1 and bank 2 deltas on `orbit` (`just firmware-orbit`). No byte-shaving rounds.
- **Green at every task end:** the task's targeted tests, then `just check`. Before the PR: `just test` and `just clippy`.

## Review focus (whole branch)

1. **An NRPN quadruple cut by a full ring.** No half selection survives. Pinned by Task 7's `ring_drop_loses_whole_events`.
2. **A pickup binding with the param moved by the panel.** It never moves the param until it re-engages. Pinned by Task 11's `pickup_rearms_after_panel_turn`.
3. **A relative encoder spun fast during a project load.** No knob lands and nothing is applied while busy. Pinned by Task 11's `relative_flood_never_lands`.
4. **Echo fighting the hand.** A swept CC never receives its own echo. Pinned by Task 15's `echo_never_returns_to_the_hand`.
5. **Closed bank 2.** No fault, MIDI deaf, maps empty, MIDI MAP `NEEDS UPDATE`. Pinned by Task 8's and Task 10's door tests.
6. **Old projects.** A `0x001E` map loads as JUMP bindings, and garbage records are skipped. Pinned by Task 10.
