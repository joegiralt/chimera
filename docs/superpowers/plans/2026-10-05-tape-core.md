# TAPE Core Implementation Plan

**Goal:** Add TAPE, Chimera's third engine: 12-bit card sources, held whole in the pool's arena, played by six RAM models (LOOP, REVERSE, PING-PONG, TRANSWAVE, SCRUB, STRETCH) under four shared macros, with a host-side WAV importer and a chunked USB `put` for sources.

**Architecture:**
- **A pure kernel first.** `dsp/tape_engine/` reads a `SourceView` (a borrowed `held` slice: a 16 B descriptor, then packed 12-bit samples) through a 32.32 head and a 4-point Hermite. Each model is a function of the view, the eased macros and the head state. None of it knows the pool, so Tasks 1–9 run now, beside pool Tasks 5–9.
- **Then the pool's plumbing.** The voice latches a `SourceId` at note-on and reads its row each block through pool Task 8's `SourceTable`. The UI loads sources from the card (pool Task 9), the meter shows them (pool Task 6), and `put` writes them.
- **Host does the heavy lifting.** WAV reading, resampling, YIN pitch, TPDF dither and TRANSWAVE mip levels live in `chimera-desktop` only. The firmware links none of them.

**Tech Stack:** Rust `no_std` (`chimera-core`), `chimera-stm32` (bench, DWT, D-cache), `chimera-desktop` (host: `hound`, `rubato`, `rustfft`, all MIT/Apache-2.0, host only per ADR 0093), `tools/chimera-usb.py`, the TLV card format (ADR 0045) on `chimera-fat`.

**Spec:** `docs/superpowers/specs/2026-10-04-tape-core-design.md` (owner-approved 2026-10-05) and ADR 0093. Read both, and `CLAUDE.md`, before any task. The pool's plan is `docs/superpowers/plans/2026-10-04-sound-pool-budget.md` on `sound-pool-budget`; its spec and ADR 0087 define every pool name used here.

**Base branch.** `tape-spec` sits on `sound-pool-budget` at 128f47c5, which holds pool Tasks 1–4: the `i16` delay, sparse Sounds (`neutral_params`, `neutral_is_a_contract`, `tests/common`'s `XorShift`), the linker AXI margin, and the arena (`GateAcked`, `next_compaction`, `source_stage`). **TAPE execution follows the pool branch:** it is rebased onto `sound-pool-budget` each time a pool task lands, and onto `main` once the pool merges. Each task below names the pool tasks it waits for; Tasks 1–9 wait for none. The pool-plan changes these tasks rely on are in `.superpowers/sdd/2026-10-05-tape-core/pool-amendments.md`, applied to the pool plan after its Task 5 commits.

**Deviations from the spec, decided here:**
- **The model kernels come before the bench.** § 10 puts the bench before any model past LOOP, but its own rows need STRETCH and TRANSWAVE. So Tasks 3–9 build every model as a host-tested kernel, unbilled and unreachable on the unit. Task 14, the first on-unit run, is still spec build step 3: the engine enters the voice, and the bench sets every bill before any model ships.
- **The core's `put` for sources is chunked** (owner, 2026-10-05), under ADR 0094 (Task 18), capped at 1 MiB, with resume reserved for TRON. `put` as merged (ADR 0092, #361) takes project files only; spec § 6 and ADR 0093 say so (updated with this plan).
- **Seeded xorshift, not `proptest`,** for the property tests: `tests/common`'s `XorShift`, on the base.
- **Every imported source has an even frame count.** A `SourceView` holds `2 · (data_len / 3)` frames, so the importer pads an odd count with one zero frame, and `SourceRef.frames` always equals the view's frames. A hand-built odd source reads back with one silent frame at its end (Task 2 tests it).
- **ROOT and PERIOD are `f32` params** (`DiskValue::Real`), in MIDI cents and frames. The header's Q16.16 period converts at pick, exactly for periods under 256 frames and within 2⁻⁸ frame below 65 536.
- **The importer's stop-band test measures from 0.5 × rate,** where § 6 puts the 80 dB stop band. § 9's "above 0.35 × rate" would be testing the transition band.
- **Card-row loads read at an offset** (`Store::read_at`, Task 17), so each UI pass reads 4 KiB, not the file from its start.

## Global Constraints

- **Code rules (CLAUDE.md):** no `unsafe` without a `// SAFETY:` comment; no heap in the audio callback; no libc; the audio thread never blocks or allocates; parameters lerp and never snap. **Never read the card in audio** (spec Intent).
- **Commits:** a terse subject, no type prefix. Stage by path, never `git add -A`.
- **Names (§ 3):** `BlockRef::Tape` stays the master stage. The engine is `EngineType::Tape` (engine code 2, ident `"TAPE"`), `BlockRef::TapeEngine` (block code 34, ident `"TAPE_ENG"`), `dsp/tape_engine/`, `TapeEngine`, `TapeEngineParams`, `TapeModel` (codes 0–5: LOOP, REVERSE, PING-PONG, TRANSWAVE, SCRUB, STRETCH; 6 is TRON's). On screen the master stage reads **REEL**.
- **Record tags (frozen once written):** `SourceHead` `0x8017`, `SourceData` `0x0018` (pool Task 9); `SourceZones` `0x0019`, `ZoneTune` `0x001A` (this plan). `FileKind::Source = 6`. `SourceRef { crc: u32, frames: u32, rate: u16 }` freezes as pool Task 8 defines it.
- **`SourceHead` payload, 34 B:** `SourceRef` 10, `shape` 1 (0 `Plain`, 1 `Transwave`, 2 `ZoneSet`), `count` 1, `root` 2 (MIDI cents, 6 000 = C4), `period` 4 (Q16.16 frames, 0 unpitched), name 16. **The CRC covers `shape`, `count`, any zone layout and the packed bytes; never a name, root or period.**
- **The descriptor, 16 B at the start of `held`:** byte 0 `shape`, 1 `count`, 2–3 `rate` (LE `u16`), 4–7 `head_frames` (LE `u32`, 0 when held whole), 8–15 zero.
- **12-bit packing (pool constraint):** `b0 = s0[7:0]`, `b1 = s0[11:8] | s1[3:0] << 4`, `b2 = s1[11:4]`; decode even `b0 | (b1 & 0xF) << 8`, odd `b1 >> 4 | b2 << 4`, sign-extended by `(x << 20) >> 20`.
- **The read:** `inc = rate / 48 000 · 2^((note·100 + pitch_cents − ROOT) / 1200)`, once a block, ramped per sample, clamped to 16. 4-point 3rd-order Hermite (Niemitalo's x-form), `1/2048` folded into its weights. Every tap clamped to `[0, frames − 1]`, or wrapped `& (N − 1)` in a transwave frame.
- **Macros:** POSITION, MOTION, TAPE, AGE and SIZE eased `EASE` = 0.3 a block (MODAL's), a note's first block taken whole. MODEL, TYPE, START and SOURCE latch at note-on; END and XFADE at a wrap.
- **Neutral (`Sound::neutral(Tape)`, a format contract):** LOOP, START 0, END 1, POSITION 0, MOTION 0, TAPE 0, AGE 0, SIZE 1, XFADE 0.1, DRAG 0.3, TYPE MONO, ROOT 6 000, PERIOD 0.
- **Bills (host estimates of the worst a whole block can sit in, per-call work in the shortest pass included, in the house manner: instructions × 1.46 × 1.1, + 12 a head for `inc` 16's cache misses, + 12 a `vdiv` left in the path, rounded up to 10; Task 2's 88-instruction head, Tasks 3 and 6's measured loops; Task 14's bench replaces them):** LOOP, REVERSE 390 (their short-loop worst, about 510, awaits a ruling); PING-PONG 560 (a clamp in a 64-frame loop at `inc` 16); SCRUB 540 (a 64-frame loop at `inc` 16, XFADE ½); TRANSWAVE 400; TRANSWAVE whose pitch can move > ±6.2 st 770; STRETCH 400; AGE running +20.
- **Copy:** `NOT A TRANSWAVE`, `POLY (UNPITCHED)`, `MIX + PLUS LOADS · {n}K`, `WON'T FIT · NEEDS {n}K, {m}K FREE`, the focus band `{NAME} · {r}K · {s} S · {n}K`; the pool's `SOURCE MISSING`, `SOURCE NOT ON CARD`, `CARD READ FAILED`. Every hint fits 216 px (ADR 0086). **One new gesture only:** MIX + PLUS on a card row.
- **The source writer is host-only until #360:** pool Task 9 gates `write_source` (and sealing) behind the `chimera-core` feature `source-writer`. `chimera-desktop` enables it (Task 11); the firmware does not, until Task 18 Step 6, after #360 is on `main`.
- **Card safety (pool Global Constraints, unchanged):** every card-writing path runs the power-cut harness and the `fail_write` / `land_then_fail` probes: no `cross_linked`, no `short`. **No card write on the owner's unit until #360 (private issue #360) is on `main`.** A bench or read-only boot may run before.
- **Flash:** each task reports one line, `flash: <free> B free on bench,orbit (<±delta>)`, from `cargo build --release -p chimera-stm32 --target thumbv7em-none-eabihf --features bench,orbit` then `rust-size target/thumbv7em-none-eabihf/release/chimera-stm32`. No per-task byte gates. Act only on real waste (a duplicated monomorphisation, a pulled-in float formatter, a table built twice). Host-only tasks report `flash: host only`.
- **Owner renders:** every engine task (Tasks 5–9) ends with renders from Task 5's rig, on a Chimera render and an open-licensed (CC0) sample, published on the one listening page. Claude's QA (peaks, the click rule, NaN) passes before the owner hears anything (QA before UAT). The owner listens by ear; findings go to GitHub issues, and the next task doesn't wait for them.
- **Precedent:** each model's module doc names its precedent with the citation the spec's Prior art table gives (S950 manual p. 32, SP-1200, Digitakt II manual § Playback modes, Octatrack OS 1.25 § Machines, Polyend Tracker v1.5 § Instrument, PPG/Waldorf, Ensoniq VFX, Morphagene manual, Niemitalo 2001).
- **Verification:** `just test`, `just clippy`, `just check`. **(unit)** marks an on-unit step, run hands-free over the USB console (`just flash`, `just flash-bench`, `python3 tools/chimera-usb.py …`).

## Review Focus

1. **A card-row load that doesn't finish** (MENU cancels it, the card errs, or the card is pulled mid-load): the arena's gap returns to what it was, nothing is published, the Part keeps playing its old source, and the band reads `CARD READ FAILED` on an error. *Task 17: `unfinished_load_leaves_the_arena`.*
2. **A USB source `put` broken mid-chunk** (cable pulled, host killed), then run again: no unsealed file is left, and the re-run writes the file once, sealed (`OK`), never `damaged`. *Task 18: `broken_put_then_rerun_writes_once`.*
3. **Tiny sources and a degenerate window** (1–4 frames; START = END; a loop under 2 ms longer than the source): every model plays finite samples, with no panic and no read outside the row. *Task 3: `tiny_sources_play_finite`; Tasks 6–8 add their models to it.*
4. **Notes at the MIDI extremes with pitch routes at their limits** (note 0 on an 8 kHz source; note 127 on 48 kHz with PITCH +24 and TAPE 1): `inc` sits at the clamp and never at 0, and the output stays finite. *Task 3: `midi_extremes_stay_finite`; Task 7 adds TRANSWAVE.*
5. **A PERIOD that doesn't fit** (larger than half the window or half the D-TIME, from a mislabelled or zone source): MONO plays as POLY, with no jump outside the window. *Task 8: `oversized_period_plays_as_poly`.*

**The protocol (the ADR's decision), minimal for the core's sizes:**
- `put /CHIMERA/TAPES/XXXXXXXX.SRC <size> <crc32>`: eight hex digits, any case; `size` ≤ 1 MiB; `crc32` over the whole file.
- First answer: `OK PRESENT` for a sealed file that verifies (no data sent); `ERR put: damaged` for a sealed file that fails (never rewritten; #267 cleans up); otherwise `READY`, after deleting any unsealed (torn) file.
- Data in **256 KiB chunks**: ADR 0092's base64 lines, then `end <crc32 of the chunk>`. The unit answers `ACK <bytes so far>`, or `ERR put: chunk`. Each chunk has its own 30 s deadline, and ADR 0092's 500 ms stall rule holds within it.
- After the last chunk: `SourceCheck` has streamed the whole file (kind, frames, CRC = stem); the whole-file `crc32` matches; read back, verify, seal; `OK`.
- **Any failure deletes the unsealed file,** then answers `ERR put: <why>`. A re-run is the retry: it's idempotent, and a sealed file answers `OK PRESENT`.
- **Resume is reserved** for TRON: `put … resume` answers `ERR put: no resume` in the core. TRON's ADR adds it, with a `Store` append, an 8 MiB cap, and zone sets.
- `ls tapes` lists `/CHIMERA/TAPES` with sizes.

**Interfaces:**
- Consumes: `SourceCheck` (Task 10); `write_source`, `Wrote`, `Store::seal` (pool 9).
- Produces: `pub fn source_target<S: Store>(s: &mut S, r: &Ready, name: FileName, stem_crc: u32) -> Result<Target, SaveError>` (`enum Target { Write, Present }`, deleting a torn file); `pub fn verify_and_seal<S: Store>(s: &mut S, r: &Ready, name: FileName, stem_crc: u32) -> Result<(), SaveError>`; `just put-tape <file>` → `chimera-usb.py put <file> /CHIMERA/TAPES/`.
