# Flash bank 2 Implementation Plan

**Goal:** Bank 2 (0x08100000–0x0817FFFF) holds sealed code that bank 1 enters through one door, written by Chimera itself from a card-staged `.bk2`, with TAPE's DSP moved there.

**Architecture:** One link, two regions: `.bank2` (header, door table, then bank-2 code) goes to a BANK2 memory region, and objcopy splits the ELF into `chimera.bin` (bank 1) and `chimera.bk2` (bank 2). A host tool seals both (SHA-256 of bank 2's body, patched into bank 1) and fails the build on any bank-1 relocation into bank 2. A pure `no_std` crate, `chimera-image`, owns the header, the judgement and the install plan; the board supplies the bank-2-only flash driver and the card reader.

**Tech Stack:** Rust 2024, no_std (thumbv7em-none-eabihf), rust-lld linker scripts, `object` + `sha2` in the host tool, Python 3 (`tools/chimera-usb.py`), just.

**Spec:** `docs/superpowers/specs/2026-10-11-bank2-design.md` (approved, owner decisions 1–8, Phase 0a/0b results). Read it before any task.

## Global Constraints

- Bank 2 is 0x08100000–0x0817FFFF (sectors S0–S3). **Never** write, erase or map for write 0x08180000+ (sectors 4–7, bootloader 1.09's slots).
- Never touch: option bytes (OPTKEYR, OPTCR), FLASH_KEYR1/CR1/SR1/CCR1, bank or mass erase (BER), 0x08000000.
- Bank 1 never calls into bank 2 without a seal match: a `Door` exists only from `chimera_image::Door::open`.
- Power loss at any instant leaves bank 1 bootable and bank 2 not `Open` (commit word last; S0 erased first).
- Every release `.bin` is strictly under 917,504 B (`just check-bin-size`); the bank-2 file is `.bk2`, never `.bin`, staged at `/CHIMERA/SYSTEM/BANK2.BK2`.
- Header at 0x08100000, 256 B, little-endian: `magic "CHIMERA2"` @0x00, `format: u16` @0x08 (=1), `flags: u16` @0x0A (=0), `body_len: u32` @0x0C (≤ 512 KiB − 256, multiple of 32), `body_crc: u32` @0x10 (CRC-32/ISO-HDLC), `door_off: u32` @0x14 (from 0x08100000, 32-aligned, inside the body), `seal: [u8; 8]` @0x18 (first 8 bytes of SHA-256 of the body), `version: [u8; 32]` @0x20 (ASCII, NUL-padded), commit `[u32; 8]` @0xE0, `0xB2C0_FFEE` ×8 = committed.
- Writer order: judge staged file fully → erase spanned sectors **S0 first** → body from 0x100 up → header words 0x00–0xDF → read back, check CRC and seal from flash → commit word last → judge again.
- Flash: PSIZE ×32 (`PSIZE_X32 = 2`), erase timeout 6,000 ms a sector, word timeout 5 ms; errors WRPERR, PGSERR, STRBERR, INCERR, OPERR, RDPERR, RDSERR, SNECCERR, DBECCERR fail the step.
- No heap, no blocking, no panic on the audio path. Every `unsafe` has a true `// SAFETY:` comment.
- Type-driven, functional core: header parsing, seal checks, judgement and install planning are pure functions in `chimera-image` with host tests.
- UX copy: `NEEDS UPDATE` (owner decision 8), `DON'T POWER OFF`. Console lines: `bank2 open <version> seal=<16 hex>`, `bank2 stale have <version>`, `bank2 empty|torn|foreign|corrupt|format <n>|unsealed`.
- Commits: terse, no type prefix. Stage by path; never stage `chimera.bin` or `docs/chimera-ui-ux-spec.md`. Never push. Never flash the unit.
- Report each task's flash delta: `rust-objcopy -R .bank2 -O binary` size of the default and ORBIT builds, before and after.
- Run real commands and report their real exit codes; `just check` is the gate before every commit that touches firmware code.
- ADRs: 0137 (bank 2 behind one door, Task 4), 0138 (TAPE Parts kept, silent and labelled while bank 2 is closed; supersedes ADR 0132 point 4, Task 12). Add both to `docs/adr/README.md`.

## Review Focus

1. **A dev build with no seal step** (`cargo build` + plain objcopy): `BANK2_SEAL` still holds `b"UNSEALED"`, so the unit reports `bank2 unsealed`, never opens, and never auto-installs. Test in Task 1 (`Seal::new(*b"UNSEALED") == None`) and Task 4 (status line).
2. **A staged `.bk2` from another build** (seal differs): never installed, bank 2 untouched, the console answers `staged: needs firmware <version>`. Test in Task 6 (`install` refuses `Stale` before any erase: SimFlash op count 0).
3. **Power cut at every flash op**, then reboot: verdict is `Open` with the staged bytes or not `Open`. Test in Task 5 (exhaustive cut loop).
4. **A torn commit word that faults (DBECC) on read at boot:** one reset, S0 erased, boot continues `Empty`, then the staged file reinstalls. Test in Task 8 (pure `boot_action` table) and the hardware checklist.
5. **A forgotten `-R .bank2`:** objcopy would emit a >1 MB `.bin` spanning both banks. Every recipe that writes a `.bin` runs `check-bin-size`; Task 2's test asserts every `rust-objcopy -O binary` line in the Justfile carries `-R .bank2`.

```rust
pub const BANK2_BASE: u32 = 0x0810_0000;
pub const BANK2_LEN: u32 = 512 * 1024;           // S0..S3
pub const HEADER_LEN: u32 = 256;
pub const FLASH_WORD: u32 = 32;
pub const MAGIC: [u8; 8] = *b"CHIMERA2";
pub const FORMAT: u16 = 1;
pub const COMMIT: u32 = 0xB2C0_FFEE;
pub const COMMIT_OFF: u32 = 0xE0;
pub struct Seal([u8; 8]);        // never b"UNSEALED", never all 0x00 or 0xFF
impl Seal { pub const UNSET: [u8; 8] = *b"UNSEALED"; pub const fn new(b: [u8; 8]) -> Option<Seal>; pub fn bytes(&self) -> [u8; 8]; }
pub struct Version([u8; 32]);   impl Version { pub fn as_str(&self) -> &str }  // up to the first NUL, non-ASCII as '?'
pub struct Header { pub body_len: u32, pub body_crc: u32, pub door_off: u32, pub seal: [u8; 8], pub version: Version }
impl Header { pub fn parse(b: &[u8; 256]) -> Result<Header, Verdict>; pub fn to_bytes(&self, committed: bool) -> [u8; 256]; }
pub trait ImageRead { fn read(&mut self, off: u32, buf: &mut [u8]) -> Result<(), ReadFail>; }
pub struct ReadFail;
pub enum Verdict { Empty, Torn, Foreign, Format(u16), Corrupt, Unreadable, Stale { have: Version }, Good(Header) }
pub fn judge(img: &mut impl ImageRead, want: &Seal) -> Verdict;
/// SAFETY contract: `read` returns the bytes at BANK2_BASE + off of this chip's bank 2.
pub unsafe trait Bank2Memory: ImageRead {}
pub struct Door { door_addr: u32, version: Version, seal: Seal }   // private fields
impl Door { pub fn open(m: &mut impl Bank2Memory, want: &Seal) -> Result<Door, Verdict>; pub fn door_addr(&self) -> u32; pub fn version(&self) -> &Version; pub fn seal(&self) -> &Seal; }
pub mod crc { pub struct Crc32; /* unchanged API: new, update, finish */ }
```
`judge` reads in the spec's order: commit word (all 0xFF → `Empty`; not `COMMIT`×8 → `Torn`), magic (`Foreign`), format (`Format(n)`), bounds (`Corrupt`: `body_len` 0, over `BANK2_LEN − HEADER_LEN`, not a multiple of 32; `door_off` < 256, ≥ 256 + body_len, or not 32-aligned), seal (`Stale{have}`), CRC over the body in 512-B reads (`Corrupt`). Any `ReadFail` → `Unreadable`.

```rust
#[repr(C)] pub struct Bank2Door { pub magic: u32 /* DOOR_MAGIC = 0xB2D0_0001 */, pub probe: extern "Rust" fn(u32) -> u32, pub table: &'static [u8; TABLE_LEN] }
```

`bank2.x` (written by build.rs; `INSERT BEFORE .text` so cortex-m-rt's `*(.text .text.*)` never takes ours):
```
SECTIONS {
  .bank2 : ALIGN(32) {
    KEEP(*(.bank2.header));
    . = ALIGN(32); __bank2_door = .;
    KEEP(*(.bank2.door));
    *(.bank2.text .bank2.text.*);
    *(.bank2.rodata .bank2.rodata.*);
    . = ALIGN(32); __bank2_end = .;
  } > BANK2
} INSERT BEFORE .text;
ASSERT(ADDR(.bank2) == 0x08100000, "bank 2 starts at 0x08100000");
ASSERT(__bank2_end <= 0x08180000, "bank 2 stays clear of bootloader 1.09's slots at 0x08180000");
ASSERT(__bank2_door == 0x08100100, "the door follows the 256-byte header");
```
Without the `bank2` feature `.bank2` is empty: then the recipe skips the `.bk2` (an empty section).


```rust
// chimera-core (pure, host-testable)
pub enum Bank2Status { Unsealed, Empty, Torn, Foreign, Format(u16), Corrupt, Stale { have: Version }, Open { version: Version, seal: [u8; 8] } }
impl Bank2Status { pub fn from_verdict(v: &Verdict) -> Self; pub fn line(&self, w: &mut impl core::fmt::Write) -> core::fmt::Result /* "bank2 open 0.2.0 02e440e2 seal=0123456789abcdef" … */; pub fn label(&self) -> &'static str /* Open → "OK", else "NEEDS UPDATE" */; }

pub enum Mpu2 { Closed, Read, Write, Open } // region 2's state; region 1 always no-access

pub fn boot_judge() -> Bank2Status;        // Read → Door::open → DOOR_CELL.open + Open, else Closed
```
MPU (RM0433 / ARMv7-M): region 1 = 0x08100000, 1 MiB, AP 000 (no access), XN, enabled — covers 0x08180000+ for good. Region 2 = 0x08100000, 512 KiB: `Closed` disabled; `Read` AP 110 (RO), XN, Normal WT (TEX 000 C1 B0); `Write` AP 011 (RW), XN, strongly-ordered (TEX 000 C0 B0); `Open` AP 110, executable, Normal WT. Every switch: DSB, ISB; into `Open`, invalidate the D-cache over 0x08100000..+512K and the whole I-cache first. Each RASR word is a `const` with a `const _: () = assert!(… == 0x…)` like `DMA_REGION_RASR`.

Boot order: in `boot` after the MPU init and before `synth`'s card step, `boot_judge()`; the status goes to `ui.set_bank2(..)` and to the console's status. Phase 1 opens the door only to call `probe` once at boot and check `probe(1) == 43` and the first and last table bytes; a mismatch closes it again and reports `corrupt`.
