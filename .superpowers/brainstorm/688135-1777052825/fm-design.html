3. Per-Operator Parameters

Tone (top of sub-page)

  • A: Waveform (8 TX81Z types)
  • B: Ratio (0.5–16.0)
  • C: Level (0–99)
  • D: Feedback (0–7)
  • E: Detune (-7..+7)
  • F: Velocity Sens (0–7)

Envelope (shift layer)

  • A+Shift: Attack Rate (0–31)
  • B+Shift: Decay1 Rate (0–31)
  • C+Shift: Decay1 Level (0–15)
  • D+Shift: Decay2 Rate (0–31)
  • E+Shift: Release Rate (1–15)
  • F+Shift: Rate Scaling (0–3)

4. UI Sub-Page Layout

FM Block (top-level page)
  ├ Algorithm — alg select (A), feedback op (B), output level (C)
  ├ OP1 — wave/ratio/level/fb/detune/vel + shift:envelope
  ├ OP2 — same layout, same encoder positions
  ├ OP3 — same layout
  └ OP4 — same layout

5. TX81Z Waveforms (8)

W1: Sine — pure sine
W2: Sine² — abs(sin) shaped
W3: Half-sine — positive half only
W4: Half-sine² — positive half, squared
W5: Quarter-sine — first/third quarter
W6: Quarter-sine² — squared quarter
W7: Clipped sine — +shaped
W8: Clipped sine² — +shaped, squared

Future: FS1R formant waveforms bolt on as W9+

6. TX81Z 5-Stage Envelope

Level
  │     AR        D1R       D2R       RR
  │    ╱╲         ╲         ╲
  │   ╱  ╲         ╲         ╲
  │  ╱    ╲         ╲         ╲
  │ ╱      ╲ D1L     ╲         ╲
  │╱        ╲─────────╲         ╲
  │                     ╲────────╲──→ 0
  └──────────────────────────────────→ Time
    Gate On                    Gate Off

AR=attack rate, D1R=first decay rate, D1L=first decay level (sustain breakpoint), D2R=second decay rate (slow drift during sustain), RR=release rate.

7. Scope

In Scope

  • 4 operators with phase modulation
  • 8 TX81Z algorithms
  • 8 TX81Z waveforms
  • 5-stage envelope per operator
  • Feedback per operator (0–7)
  • Ratio mode (0.5–16)
  • Detune, velocity sensitivity
  • Rate scaling
  • FM chain + block defs + sub-pages
  • Integration with existing signal chain

Out of Scope (later)

  • Fixed frequency mode
  • FS1R waveforms
  • TX81Z preset import/export
  • LFO → operator modulation
  • Per-operator key scaling
