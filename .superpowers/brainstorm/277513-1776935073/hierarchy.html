Data Hierarchy
PROJECT (saved to SD card)
├─ Mixer state (levels, pans, sends for B1-B6)
├─ Track B1 → Patch "Acid Bass"
├─ Track B2 → Patch "Pad Wash"
├─ Track B3 → Patch "Pluck"
├─ Track B4 → Patch "(init)"
├─ Track B5 → Patch "(init)"
└─ Track B6 → Patch "(init)"

PATCH (saved to SD card, loadable per-track)
├─ Name "Acid Bass"
├─ Chain (which blocks in what order)
├─ Audio block params (osc, filter, drive, folder, reverb, etc.)
└─ Mod block params (LFOs, envelopes, mod matrix routing + amounts)

CHAIN (the template — which blocks, in what order)
├─ Audio blocks [Pizza → Drive → Filter → Folder → Reverb]
└─ Mod blocks [Env1, Env2, LFO1]

UI Flow

Normal: tap B1 → navigate to B1's chain
Double-tap B1: → open patch browser for B1
Patch browser shows: list of saved patches + "(init)" defaults per chain type
Select patch: → loads chain + params + mods into B1
