Preset System Design

Full architecture — review each section

1. Data Model

Core Types (chimera-core)
/// A saved sound — chain definition + parameter state + mod routing
Patch {
  name: [u8; 16],       // ASCII, null-padded
  chain_id: ChainType,   // which chain template (PizzaPoly, Modal, FM...)
  params: ParamSnapshot, // all audio block params
  mod_state: ModState,   // mod matrix routing + amounts
}

/// 32 patch slots in RAM — the sound pool
SoundPool {
  slots: [Option<Patch>; 32],
}

/// Full synth state — references into the sound pool
Project {
  name: [u8; 16],
  pool: SoundPool,
  tracks: [TrackAssignment; 6], // B1-B6 → pool slot index
  mixer: MixerState,           // levels, pans, sends
}

TrackAssignment {
  slot: Option<u8>,  // index into pool (None = silent)
}

2. Shared References (Digitone Model)

Pool:  [0: "Acid Bass"] [1: "Pad Wash"] [2: "Pluck"] [3: (init)] ... [31: (empty)]

Track B1 → slot 0 ●
Track B2 → slot 1 ●
Track B3 → slot 0 ● ← same slot as B1, edits affect both
Track B4 → slot 2 ●
Track B5 → None (silent)
Track B6 → None (silent)

3. UI Flow

Load patch into track:
  Double-tap B1 → Patch Browser opens for B1
  Browse pool slots (encoder scroll) → select → B1 now references that slot

Edit patch (current track):
  Normal navigation — editing params edits the referenced pool slot
  All tracks sharing that slot hear changes immediately

Init patch:
  In patch browser: select "(init)" → writes fresh default into the slot

Copy patch to new slot:
  Future feature — not in first iteration

4. Serialization Format

Patch binary (for future SD card):
[magic: u32] [version: u8] [chain_type: u8] [name: 16 bytes]
[params: ParamSnapshot as raw bytes]
[mod_state: ModState as raw bytes]

Version field enables forward-compatible format changes.
For RAM-only phase: just use the Patch struct directly, no serialization needed.

5. First Iteration Scope

In Scope

  • Patch struct + SoundPool + Project types
  • Track → slot assignment
  • Patch browser UI (double-tap B1-B6)
  • Init patch per chain type
  • Load patch into track
  • Serialization format (ready for SD)

Out of Scope (later)

  • SD card driver (SPI2)
  • FAT filesystem
  • Save/load from SD
  • Copy/paste patches between slots
  • Project save/load
  • Factory preset bank
